# Coverage methodology

Run:

```sh
cargo +1.95.0 install cargo-llvm-cov --version 0.8.6 --locked
rustup component add llvm-tools-preview --toolchain 1.85.0
make coverage
```

The coverage utility is compiled with a newer host toolchain because version
0.8.6 requires Rust 1.87+, but it instruments this crate with the pinned Rust
1.85.0 project toolchain. This does not change the crate's MSRV or artifact.

`go.out` and `go-functions.txt` are generated by Go's statement-block coverage.
`rust.json` is LLVM source-based coverage. `report.json` separates the complete
Rust library from the three main algorithm modules and retains whole-target
totals. Go statements and Rust lines/regions are different measurement models;
their numeric delta is reported solely for transparency.
